# Launglon landslides 2026: drone tile sets (2)

Web-map tiles (512 px WebP, XYZ scheme; Leaflet `tileSize: 512, zoomOffset: -1`) for the dashboard at
https://geonet-myanmar.github.io/launglon-landslides-2026/, hosted separately so that site and the first tile repo
(geonet-myanmar/launglon-landslides-tiles) stay under GitHub Pages' 1 GB limit.

| folder | survey | resolution |
|---|---|---|
| `tizit/` | Ti Zit, Launglon Township, flown 9 Oct 2026 (two deliveries joined) | 10.0 cm, tiles z13-z20 |

Built by `scripts/10_tiles.py tizit` in the `launglon-landslides-2026` repo; do not edit by hand.
